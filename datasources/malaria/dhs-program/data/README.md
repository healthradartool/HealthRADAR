# Data Source: dhs-program

This README serves as a catalog and description of the origin of the files used in the corresponding data source page, which can be found in the `datasources/malaria/dhs-program/` directory.

## Data Files

No data files were used in the creation of this data source page. The data is accessed directly through the [rdhs R package](https://docs.ropensci.org/rdhs/), which interfaces with the [DHS Program API](https://api.dhsprogram.com/#/index.html).

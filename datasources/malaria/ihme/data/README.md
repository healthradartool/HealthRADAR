# Data Source: ihme

This README serves as a catalog and description of the origin of the files used in the corresponding data source page, which can be found in the `datasources/malaria/ihme/` directory.

## Data Files

-   [IHME-GBD_2021_DATA-05f6b66f-1.csv](https://github.com/healthradartool/HealthRADAR/raw/refs/heads/main/datasources/malaria/ihme/data/IHME-GBD_2021_DATA-05f6b66f-1.csv): Well described in the HealthRADAR page. Find this data [here](https://vizhub.healthdata.org/gbd-results/).

-   [IHME_INSECTICIDE_TREATED_BEDNETS_SUB_SAHARAN_AFRICA_1999_2008.xls](https://github.com/healthradartool/HealthRADAR/raw/refs/heads/main/datasources/malaria/ihme/data/IHME_INSECTICIDE_TREATED_BEDNETS_SUB_SAHARAN_AFRICA_1999_2008.xls): as mentioned in the page, can be found on the [portal via Home > Estimate Sub-Saharan Africa Insecticide-Treated Bed Nets 1999-2008](https://ghdx.healthdata.org/record/ihme-data/sub-saharan-africa-insecticide-treated-bed-nets-1999-2008) after logging in and navigating to the "Files" tab.
